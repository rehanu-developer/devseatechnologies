# DevSea Technologies Landing Page

Responsive vanilla HTML, CSS, and JavaScript landing page for DevSea Technologies.

Open `index.html` directly, or serve this folder with any static web server.

## Files

- `index.html` — semantic page structure
- `styles.css` — responsive styling and design tokens
- `script.js` — mobile navigation, active-section behavior, and contact form email handoff
- `assets/` — logo files, section imagery, icons, and team/service assets

## GitHub Pages

Upload the contents of this folder to the root of the repository, then enable GitHub Pages from the `main` branch and `/root` folder.
